# Mohith M — Portfolio (React + JavaScript + CSS)

## Run
```bash
npm install
npm run dev      # local dev server
npm run build    # production build in /dist
```

## Structure
- `src/App.jsx` — page layout
- `src/sections/` — Navbar, Hero, About, Skills, Work, Education, Contact, Footer
- `src/components/` — Tilt (3D hover), Reveal (scroll), CountUp, Icons, hooks
- `src/data.js` — all text content (edit skills, projects, contact here)
- `src/styles.css` — all styling and animations
- `src/assets/mohith-profile.jpg` — profile photo
- `public/resume.pdf` — resume file (kept, not linked from the hero button)
